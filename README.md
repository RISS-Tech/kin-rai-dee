🍲 ทุกมื้อ (TooKMUE) — กินอะไรดี

เว็บแอปพลิเคชันแบบ Progressive Web App (PWA) สำหรับช่วยตัดสินใจมื้ออาหาร จับคู่สำรับไทย–นานาชาติ เคลียร์วัตถุดิบในตู้เย็น วางแผนตารางอาหาร 7 วัน และคุมงบประมาณค่ากินในชีวิตประจำวัน

🌐 ใช้งานเว็บแอป: https://tookmue.pages.dev/

✨ ฟีเจอร์หลัก (Key Features)

🎯 วงล้อสุ่มเมนู 4 โหมดอัจฉริยะ

มื้อหลัก: สุ่มเมนูอาหารจานเดียวและกับข้าว พร้อมตัวกรองด่วน (งบประหยัด ≤50฿, ทำเร็ว ≤15 นาที, รสจัดจ้าน, ไม่เผ็ด) และตัวเลือกอารมณ์มื้ออาหาร

ตั๋วทิพย์ (Passport Mode): บินลัดฟ้าสุ่มชิมอาหารนานาชาติจาก 46 ประเทศ/ภูมิภาค

ของหวาน & เครื่องดื่ม: สุ่มขนมไทย คาเฟ่ และเครื่องดื่มเติมความสดชื่น

เมนู-ตู้เย็น (Fridge-to-Table): กรอกวัตถุดิบที่เหลือในตู้เย็นเพื่อจับคู่เมนูทำกินเอง พร้อมคำนวณคะแนนความสร้างสรรค์

🥢 ระบบจับคู่สำรับอัตโนมัติ (Food Pairing)

แนะนำเมนูกับข้าวที่เข้ากันและของหวาน/เครื่องดื่มตบท้ายมื้อ โดยหลีกเลี่ยงโปรตีนหลักซ้ำกัน

ระบบตัดเมนูที่ "เมื่อวานเพิ่งกินไป" ออกจากการสุ่มรอบถัดไปโดยอัตโนมัติ

สร้างการ์ดสรุปสำรับเป็นรูปภาพสำหรับแชร์ส่งเข้า LINE หรือโซเชียลมีเดียได้ทันที

📖 คลังเมนูอาหาร 264 รายการ

อาหารไทย 4 ภาค: 100 เมนู (ภาคกลาง, ภาคเหนือ, ภาคอีสาน, ภาคใต้)

อาหารนานาชาติ: 114 เมนู (ครอบคลุม 46 ประเทศและภูมิภาค)

ของหวาน: 25 เมนู (ขนมไทยและเบเกอรี่/คาเฟ่)

เครื่องดื่ม: 25 เมนู (ชา กาแฟ และน้ำสมุนไพร)

รองรับการเพิ่ม เมนูส่วนตัวของฉัน ลงในคลังและวงล้อสุ่ม

📅 ตารางอาหาร 7 วัน & รายการจ่ายตลาดอัตโนมัติ

สุ่มจัดมื้อกลางวันและมื้อเย็นครบทั้งสัปดาห์ (รองรับทั้งโหมดทั่วไปและโหมดประหยัดงบ)

สรุปรายการวัตถุดิบที่ต้องซื้อจากตารางอาหารให้อัตโนมัติ พร้อมช่องติ๊กเช็กรายการ

💰 กระเป๋าคุมงบค่ากิน (Food Budget Wallet)

ตั้งเป้าหมายงบค่าอาหารรายสัปดาห์ บันทึกรายจ่ายค่าอาหาร และติดตามยอดใช้จ่ายสะสมรายสัปดาห์/รายเดือน

🏆 สมุดพาสปอร์ตนักชิม & ระบบซิงก์คลาวด์

สะสมแต้ม XP, เลื่อนระดับฉายา, เช็กอินปิ่นโตสะสมวัน (Daily Streak) และสะสมตราประทับประเทศ

รองรับการเข้าสู่ระบบด้วยบัญชี Google (Gmail) เพื่อซิงก์ข้อมูลความคืบหน้าข้ามอุปกรณ์

🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

Frontend: HTML5, CSS3, Vanilla JavaScript (ES Modules)

PWA & Offline Support: Web App Manifest (manifest.json) และ Service Worker (sw.js) แบบ Network-First สำหรับข้อมูลเมนู และ Runtime Caching (Cache-First) สำหรับรูปภาพ

Backend & Authentication: Firebase Authentication (Google Sign-In) และ Cloud Firestore

Hosting & Deployment: GitHub + Cloudflare Pages

🖼️ มาตรฐานการจัดการรูปภาพ (Image Guidelines)

รูปภาพชุดใหม่ทั้งหมดใช้รูปแบบไฟล์ .webp ความกว้าง 800px เพื่อความคมชัดและโหลดเร็วบนมือถือ

ตั้งชื่อไฟล์ตาม รหัสเมนู เท่านั้น เช่น TH-C01.webp, INT-01.webp, DES-001.webp, BEV-001.webp เพื่อป้องกันปัญหาอักขระพิเศษใน URL
