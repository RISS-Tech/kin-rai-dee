# 🍲 ทุกมื้อ (TooKMUE)

เว็บแอปพลิเคชัน (PWA) ช่วยตัดสินใจมื้ออาหารและจับคู่สำรับแบบครบวงจร **เล่นฟรี 100% ไม่มีค่าสมัครสมาชิก และไม่ต้องดาวน์โหลดแอป** พัฒนาขึ้นเพื่อแก้ปัญหา *"มื้อนี้กินอะไรดี?"* ทั้งกินคนเดียวและกินกับกลุ่มเพื่อน

🌐 **ใช้งานจริงได้ที่:** [https://tookmue.pages.dev/](https://tookmue.pages.dev/)

---

## ✨ ฟีเจอร์หลัก (เวอร์ชันล่าสุด `v21`)

### 1. หน้าแรกแบบ Photo-First & สลับรูปแบบตัวสุ่ม
* **🖼️ การ์ดภาพอาหารจริง (Photo-First Card Deck):** แสดงภาพอาหารจริงเต็มตาพร้อมธงชาติ/ภูมิภาค งบประมาณ เวลาปรุง และแถบภาพย่อด้านล่าง (รองรับการปัดซ้าย/ขวาเพื่อสุ่ม)
* **🎡 วงล้อคลาสสิก (Classic Spin Wheel):** สลับกลับมาใช้วงล้อหมุนแบบดั้งเดิมได้ทุกเมื่อ พร้อมเอฟเฟกต์เสียงและแอนิเมชันลากหมุน
* **⏰ แถบบริบทอัจฉริยะ (Smart Context Strip):** ทักทายตามช่วงเวลาจริง (เช้า/เที่ยง/บ่าย/เย็น/ดึก), แสดงยอดงบค่ากินคงเหลือสัปดาห์นี้แบบเรียลไทม์ และปุ่มลัด 1 คลิกที่ปรับตามช่วงเวลา

### 2. 5 โหมดสุ่มอาหารครบทุกมื้อ
* **🍚 มื้อหลัก:** อาหารไทย 4 ภาค และอาหารนานาชาติ
* **✈️ ตั๋วทิพย์:** บินสุ่มอาหารนานาชาติ **51 ประเทศ** เพื่อสะสมตราประทับในสมุดพาสปอร์ตนักชิม
* **🍨 ของหวาน:** แยกหมวดขนมไทยและของหวานคาเฟ่ชัดเจน (25 เมนู)
* **🥤 เครื่องดื่ม:** แยกหมวดชา กาแฟ และน้ำสมุนไพรชัดเจน (25 เมนู)
* **🧊 เมนู-ตู้เย็น (Fridge-to-Table):** พิมพ์วัตถุดิบที่เหลือในตู้เย็นเพื่อรับไอเดียเมนูประยุกต์ + คะแนนเมนูสร้างสรรค์ และจับคู่เมนูตรงสเปกในคลัง

### 3. โหมดเฉพาะทาง & การคัดกรองก่อนสุ่ม
* **☪️ โหมดอาหารฮาลาล (Global Halal Mode):** สวิตช์เปิด/ปิดระดับทั้งแอป คัดกรองเมนูหมู ส่วนผสมแฝง (เบคอน/แฮม/กุนเชียง) แอลกอฮอล์/มิริน ไส้กรอก และปลาร้าออก 100% พร้อมปรับระบบจับคู่สำรับ โหมดตู้เย็น และตาราง 7 วันเป็นฮาลาลอัตโนมัติ
* **🦂 โหมดเมนูแปลก (Exotic Mode — ปิดไว้เป็นค่าเริ่มต้น):** ซ่อนเมนูแปลกไทยและทั่วโลกทั้ง **23 รายการ** ออกจากกองสุ่มปกติ เมื่อผู้ใช้เปิดเองสามารถเลือกสุ่มตามระดับความโหด (`💀` / `💀💀` / `💀💀💀`), เล่นโหมด **`🎲 ท้าเพื่อน (Party Dare)`** จับคู่ชื่อเพื่อน × เมนูแปลก พร้อมแชร์การ์ดเข้า LINE และรับโบนัส `+50 XP`
* **🎛️ แผงตัวกรองแบบพับได้ & จัดถาดคัดเอง (`5` หรือ `8` รายการ):** กรองสไตล์อาหารเฉพาะทาง (`🥗 สายคลีน`, `🥬 มังสวิรัติ`, `🍢 สตรีทฟู้ด`, ซดน้ำ, ของทอด, เมนูเส้น), งบประมาณ, เวลา, ความเผ็ด, ตัดเมนูที่กินไปเมื่อวาน รวมถึงเลือกสุ่มเฉพาะ **`❤️ เมนูโปรด`** หรือจิ้มเลือกเองใน **`🎯 ถาดคัดเอง`**

### 4. ฟีเจอร์กลุ่มเพื่อน & การจัดสำรับ
* **👥 วงล้อกลุ่มเพื่อน / ออฟฟิศ (Group Spin):**
  * *รวมเงื่อนไขทั้งโต๊ะ:* ติ๊กเงื่อนไขที่ทุกคนกินได้ร่วมกัน (ฮาลาล, ไม่เผ็ด, เร็ว ≤15 นาที, มังสวิรัติ, งบต่อคน) เพื่อสุ่มเมนูกลาง
  * *ใส่เมนูคนละอย่าง:* ให้เพื่อนเสนอชื่อเมนูหรือร้าน (2–8 รายการ) แล้วสุ่มตัดสิน พร้อมสร้างการ์ดมติกลุ่มแชร์เข้า LINE
* **🥢 สำรับ 3 ชิ้นแนะนำตามเพดานงบ (Food Pairing):** จับคู่ `จานหลัก + คู่กับข้าวไม่ซ้ำโปรตีน + ของหวาน/เครื่องดื่ม` เลือกเพดานงบรวมได้ (`ไม่จำกัด`, `≤120฿`, `≤180฿`, `≤250฿`) และกดบันทึกกินทั้งสำรับในคลิกเดียว (`+40 XP`)

### 5. ระบบวางแผน คุมงบ และ Gamification
* **📅 ตารางมื้อ 7 วัน & รายการจ่ายตลาด:** สุ่มจัดมื้อกลางวัน–เย็นครบสัปดาห์ (โหมดปกติ/ประหยัดงบ) สรุปรายการวัตถุดิบต้องซื้ออัตโนมัติ และกดบันทึกมื้อที่กินแล้วเชื่อมเข้ากระเป๋าคุมงบได้ทันที
* **💰 กระเป๋าคุมงบค่ากิน (Food Budget Wallet):** ตั้งงบรายสัปดาห์ ติดตามยอดใช้จ่ายรายสัปดาห์/รายเดือน เชื่อมยอดอัตโนมัติจากการสุ่ม โหมดตู้เย็น และตาราง 7 วัน
* **🏆 ฉายา, XP, ภารกิจประจำสัปดาห์ & Cloud Sync:** ล็อกอินด้วย Google (Gmail) เพื่อซิงก์แต้ม XP, ฉายา, อวตาร, Daily Streak, สมุดพาสปอร์ต 51 ประเทศ, ภารกิจประจำสัปดาห์ (4 ภารกิจ รีเซ็ตทุกวันจันทร์) และเมนูส่วนตัวข้ามอุปกรณ์

## 🛠️ เทคโนโลยีและโครงสร้างโปรเจกต์

* **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6+), Canvas API (Wheel & Shareable Cards), Web Audio API
* **Backend & Sync:** Firebase Authentication (Google Sign-In) & Cloud Firestore
* **PWA & Offline:** Service Worker (`tookmue-v21-truemoney-qr`) แบบ Network-First สำหรับโค้ด/ข้อมูล และ Runtime Cache-First สำหรับโฟลเดอร์ `images/`
* **Hosting:** Cloudflare Pages (Deploy อัตโนมัติจาก GitHub Repository `RISS-Tech/kin-rai-dee`)

### โครงสร้างไฟล์หลัก
```text
├── index.html          # หน้าแอปหลัก + โมดัลฟีเจอร์ทั้งหมด + โมดูล Firebase Sync
├── styles.css          # สไตล์ระบบทั้งหมด (โทนครีมอบอุ่น, ส้มพริก, เหลืองขมิ้น, เขียวสมุนไพร)
├── app.js              # ลอจิกหลักทั้งหมด (Photo-First, Wheel, Halal, Exotic, Group Spin, Wallet, Quests)
├── menus.json          # ฐานข้อมูล 298 เมนู พร้อมแท็กเฉพาะทางและการจับคู่สำรับ
├── sw.js               # Service Worker สำหรับ PWA & Runtime Image Caching (v21)
├── manifest.json       # Web App Manifest
├── admin.html          # หน้าจัดการระบบสำหรับผู้ดูแล
├── privacy.html        # นโยบายความเป็นส่วนตัว
├── truemoney-qr.jpg    # QR PromptPay E-Wallet (TrueMoney Wallet) สำหรับสนับสนุนผู้พัฒนาตามสมัครใจ
├── icon.svg / png      # โลโก้และไอคอนแอป TooKMUE
└── images/             # คลังรูปภาพอาหารจริงทั้งหมด 298 เมนู
```

## 🚀 การอัปเดตและ Deploy

โปรเจกต์เชื่อมต่อกับ **Cloudflare Pages** โดยตรง เมื่ออัปโหลดไฟล์ที่แก้ไขและกด `Commit changes` บน GitHub ระบบจะ Build และ Deploy ขึ้น `https://tookmue.pages.dev/` ภายใน 1–2 นาที
* **การเพิ่มเมนูใหม่:** เพิ่มรายการใน `menus.json` (รัน `id` ต่อจากหมวดเดิม, ระบุ `mode`, `is_halal`, `is_exotic`) และอัปโหลดรูป `.webp` (กว้าง `800px`) ลงโฟลเดอร์ `images/` ระบบจะอัปเดตจำนวนเมนูและแคชรูปให้อัตโนมัติ
